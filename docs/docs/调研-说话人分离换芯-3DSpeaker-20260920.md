# 调研：说话人分离换芯（自研 → 3D-Speaker）

日期：2026-09-20　结论：**换芯定裁，3D-Speaker 上车**（2026-09-19 用户拍板）。
本文是决策记录与调研存档，完整实验日志见 `eval/tuning_log.md` 与
`scd_bench/NOTES-用法研究.md`。

## 1. 背景：为什么换

自研分离 = FSMN VAD 切段 + ERes2NetV2 声纹向量 + 阈值/簇算法逐句认人，问题：

1. **分人错**：长会议同一人的句子隔三差五被标成别人；旧裁判件上出现过
   "整片全员并入陌生人1"的塌缩（aishell4 L 会自研 52.6% vs 3D-Speaker 36.0%）。
2. **无缝换人零能力**：VAD 靠静音切分，两人零间隙衔接必然并成一段。
3. 参数一堆（anon_cluster_threshold / anon_split_gap / tail_attach …），互相牵扯，
   每次调优都是全链路盲调，修一处塌一处。

## 2. 候选方案（当时的三条路）

| 方案 | 说明 | 淘汰/入选理由 |
|---|---|---|
| **3D-Speaker**（阿里通义，ModelScope） | VAD + CAM++ 声纹嵌入 + 谱聚类一体化，官方 AISHELL-4 DER 10.30% | ✅ 入选：中文会议域原生、CPU 可跑（RTF≈0.06）、开箱即用 |
| pyannote（社区标准） | 重叠检测强（segmentation 模型） | pyannote/segmentation-3.0 是 HF gated 模型，无 token 跑不通；单独立项 |
| 自研调参救活 | 阈值定档 0.48、VAD 回 250 等定档后 | 定档后 DER 10.1%，仍输 3D-Speaker；且天花板低 |

另核查过：ModelScope 的 EEND-OLA 模型（英文 8k callhome 域，不匹配中文 16k 会议，
排除）；CapsWriter-Offline（无分离能力，仅参考）。

## 3. 擂台赛数据（关键证据）

口径：`scd_bench/scripts/der_eval.py`，100ms 帧、匈牙利最优映射、双 collar 档；
公平条件 = 全部经 GTCRN 降噪。

| 件 | 3D-Speaker+GTCRN | 自研（同尺） |
|---|---|---|
| M 会 5min 切片 | **4.77%**（strict 6.33） | 8.86%（c0.25） |
| M 会全曲 38min | 9.71% | 12.3%（旧口径基线） |
| L 会全曲 39min | 4.88% | — |
| rotate_m30_s5（6人×30s 轮转裁判件） | **7.66%**（6/6 标签全对） | — |
| rotate40_s3（跨会 6 人轮转，GT 修正后） | 5.79% | — |
| 无缝打散 m_rr_gap0_s7 | 36.0% | 52.6%（整片 1 标签塌缩） |

要点：

- 3D-Speaker 赢在 **confusion（分人准）**，输在 miss（VAD 边界侵蚀）——而
  miss 由 GTCRN 前置降噪救回大半（生肉 26.2% → 降噪 4.77%）。
- 冷知识：aishell4 L 会与 M 会的 001-M 实为同一人（ERes2NetV2 cos 0.686），
  rotate40 修正即据此把 001-M 与 L_001-M 视为同一人重评。
- **已知短板（不解决也不影响上车决策）**：无缝换人两家都治不了（同范式 VAD 切段），
  根治需 pyannote segmentation 类重叠检测（要 HF token，单独立项）；
  <40 子段走 AHC 短段分支（短会议人数估计不可靠）；每场独立聚类，匿名编号
  每场归零；>15 人不可用（max_num_spks 上限）。

## 4. 接入架构（换芯一期，2026-09-20 完成）

```
会末终版（reannotate，唯一生产路径）：
原始 PCM → 本地 GTCRN 降噪 → 本地 diarize3ds.diarize（CPU，出匿名分段
{start,end,cluster_id}）→ GPU /identify_segments（逐段 SeACo ASR[热词/标点/ITN]
+ 逐簇 ERes2NetV2 对声纹库匈牙利一对一认人，未命中编"说话人N"）→ utterances_re 落库
```

- git：一期 A `bc705d1`（依赖并入项目 venv + diarize3ds wrapper，等价性验收
  0.00pp）；一期 B `bd0122d`（reannotate 切新流程 + GPU 端点 commit `83cf988`）。
- 聚类参数收敛到 `config.py diar3ds_*`，默认 = scd_bench 评测值。
- **无 legacy 开关**：3D-Speaker 是唯一会末分离路径，新链路任一环节失败 =
  终版失败并记日志，绝不静默回退旧聚类。旧代码封存 `_legacy`（git 可回滚）。
- 会中批次（8~15s 增量）仍走旧 GPU `/meeting_chunk` 不变——批次只出"草稿"，
  终版才是权威结果。

## 5. 使用注意（给后续维护者）

1. 3D-Speaker 源码在 `server/third_party/3D-Speaker`（gitignore，
   `server/scripts/fetch_3dspeaker.sh` 可重拉）；模型缓存在 `server/models/cache`。
2. 认人仍靠声纹库比对（3D-Speaker 只出匿名标签），注册流程不变。
3. 想调参：改 `config.py diar3ds_*` 后重启 8010；参数含义见注释。
   （>40 子段才走谱聚类，短会议调参无效——AHC 分支只有 0.4 阈值可动。）
4. 验收方法：`server/scripts/replay_wav.py <wav> --speed 2` 重放 +
   `server/scripts/replay_der.py <meeting_id> --rttm <gt>` 评分，
   与 scd_bench 基准对比（M5min 4.77 / rotate_m30 7.66 / rotate40 5.79，±2pp 内）。
