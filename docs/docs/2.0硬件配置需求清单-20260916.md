### 选型总则（老师口径）
- 不加钱买用不上的功能（AEC、重降噪、级联全砍）
- 加钱只加在"听得出来/看得出来"的地方：麦克风拾音真实度、摄像头解析力与变焦
- 无线是可选项而非硬性需求——2.4G 方案音质达标则上，不达标回有线

## 二、麦克风

### ✅ 已确认

| 项 | 值 | 说明 |
|---|---|---|
| 采样率 | **16 kHz** | ASR 标准输入 |
| 位深 | **16 bit** | 够用，更高对识别率零增益 |
| 接口 | **USB**，必须免驱（UAC 标准） | 浏览器直取，不装软件 |
| 形态 | 会议全向麦（桌面中央） | 覆盖半径 3~6m |
| 声道 | **单声道即可** | 双声道只给方位粗线索、对认人无实质帮助（认人靠声纹模型）；按通道区分人属于每人一麦的极端方案，贵且布线乱，不上 |

### 选型内部核查项（按已回收的答案更新）

| 项 | 要求 |
|---|---|
| 连接方式 | **2.4G 无线（USB 接收器）优先，有线备选**——蓝牙排除（通话切窄带毁音质）；调研核心是 2.4G 方案音质/稳定性实测能否达标 |
| AEC 回声消除 | **非必需**（Q1=不外放），不为其付费 |
| 降噪 DSP | 够用即可（Q3=噪音不大），不过度配置 |
| 拾音 | 单机专业全向麦（Q2），看真实拾音半径与远场衰减 |
| 音质 | **核心指标**（Q5：录音要"稍微专业一点"、加钱要听得出来）：关注麦克风单元规格、采样规格是否原生支持 16k/16bit 以上直出、有无音损处理 |
| 长时间工作 | 电池续航（无线款）≥一场会（按 3~4 小时算），或边充边用 |
| 兜底录音 | 优先选自持本地存储/插卡备份的型号（断网兜底，内部倾向） |
| 免驱 | 无线款=接收器免驱；有线款=UAC 免驱 |

## 三、摄像头

### ✅ 已确认

| 项 | 值 | 说明 |
|---|---|---|
| 用途 | **覆盖手写白板**（老师已提，定案）+ PPT 兜底 | 白板是 VLM 调试重点（手写+人挡板+斜角），到货第一天先验 |
| 分辨率 | **1080p 起步**，会场大/屏幕远上 **4K** | PPT 文字可读下限 |
| 帧率 | 无需高帧率 | 抽帧喂 VLM，5~10fps 采样足够 |
| 对焦 | **自动对焦/光学变焦必须** | 拍 3~8m 外屏幕，定焦糊字 |
| 形态 | USB 云台（PTZ）或可手动转向 | 白板有人走动写，固定机位容易拍空 |

### 选型内部核查项

| 项 | 要求 |
|---|---|
| **抗频闪（50/60Hz 防闪烁）** | 拍投影画面不滚条纹，**必备** |
| 宽动态（WDR） | "屏幕亮、环境暗"高反差场景防过曝 |
| 光学变焦 | 机位距屏幕 5m 以上要 3x+；警惕廉价插值"4K" |
| USB 线长 | >5m 需有源延长线/光纤线，随货一起买 |
| 供电 | 云台 4K 款可能要外接电源 |
| 隐私盖/指示灯 | 顺带 |

## 四、会场电脑与链路（B 方案隐含依赖）

| 项 | 要求 |
|---|---|
| 电脑性能 | 要求极低（屏幕共享+两路 USB 采集） |
| **电脑必须插网线** | WiFi 抖动是 1.0 音频"一顿一顿"的同款坑 |
| 采集方式 | 浏览器 getUserMedia，麦+摄像头同时授权 |
| 远程参会声音 | 屏幕共享勾"分享系统音频"直采，不走麦克风 |
| 流程 | 开会 → 开网页 → 授权 → 点开始；写进使用说明 |
