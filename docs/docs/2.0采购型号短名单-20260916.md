## 选型总则（按老师口径）

- **全链路有线**：免驱 USB 直连会场电脑。无电池/充电管理、无断连变量、成本最低、验收最简单。
- 蓝牙任何情况下都排除——通话时蓝牙切 HFP 窄带档（8~16kHz），音质崩塌（[森海塞尔官方说明](https://support.sennheiser-hearing.com/hc/zh-cn/articles/34975070949789-%E8%93%9D%E7%89%99%E4%BC%98%E5%85%88%E7%BA%A7%E5%92%8C%E9%85%8D%E7%BD%AE%E6%96%87%E4%BB%B6%E4%BF%A1%E6%81%AF)）。
- AEC 不付费（不外放）；降噪够用即可；核心指标是**拾音真实度 + 远场衰减**。
- 老师 Q4"倾向无线"以"效果不好优先有线"为前提；现无线化收益≈0、代价实打实，按有理有据回有线，已获项目负责人认可。

## 二、摄像头短名单（v3：先行采购项）

**MAXHUB SC51S** ⭐：1080p，**10x 光学变焦**，云台+遥控，USB 免驱，**无麦克风**（拾音麦 BM 系列为另购件），¥1229。
- 购买渠道纪律：**自营/官方旗舰店**，不选第三方专卖店（"使用后不支持 7 天无理由"的店直接 pass）。
- 下单前客服两问：① 上机实拍测试后能否 7 天无理由退；② 有无 50/60Hz 抗频闪设置。
- 备选：海康自营会议摄像机（DS-UVC 云台变焦款，低照度强项，适配"屏幕亮环境暗"会场）。

**摄像头硬门槛（到货必验）**：① 50/60Hz 抗频闪（拍投影防条纹）；② 自动对焦稳定（对投影画面不来回切）；③ 3~8m 实测拍屏/白板，VLM 读出 14pt+ 文字。

**摄像头为什么不走无线（2026-09-16 对齐结论）**：
- 2.4G 免驱：带宽余量为零（2.4G 实际吞吐 10~20Mbps vs 1080p H.264 需 4~8Mbps），会议室 2.4G 被 WiFi/蓝牙挤占，视频最怕丢包；大厂无此形态产品，白牌无保障。
- WiFi 摄像机（RTSP）：对我们"抽帧喂 VLM"的用法技术上可行、本地拉流无数据安全问题，但需配网管理 + RTSP 拉流/断线重连开发（≈C 方案 2~4 天）+ 音视频双流对齐，而会场本来就有电脑，USB 零开发——花钱买复杂度，不值。
- 5G 无线 HDMI 图传 + 采集卡：贵且链路复杂，不议。
- 结论：摄像头有线（>5m 用有源 USB 延长线）。
