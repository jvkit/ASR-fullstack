> 2026-09-16 ｜ 依据：`2.0硬件配置需求清单-20260916.md` v6（老师 5 答已锁定）
> 预算基准：全套 2~3k，可上浮；钱优先投麦克风（"听得出来"的加钱才加）

## 选型总则（按老师口径）

- 无线（Q4 倾向）**必须 2.4G 接收器方案**；蓝牙排除——通话时蓝牙切 HFP 窄带档（8~16kHz），音质崩塌（[森海塞尔官方说明](https://support.sennheiser-hearing.com/hc/zh-cn/articles/34975070949789-%E8%93%9D%E7%89%99%E4%BC%98%E5%85%88%E7%BA%A7%E5%92%8C%E9%85%8D%E7%BD%AE%E6%96%87%E4%BB%B6%E4%BF%A1%E6%81%AF)）。2.4G 数字链路音质接近有线、免驱、麦与电脑间无束缚（[2.4G vs 蓝牙对比](https://www.hzliwang.com.cn/jiejuefangan/2246.html)），符合"无线"诉求。
- AEC 不付费（不外放）；降噪够用即可；核心指标是**拾音真实度 + 远场衰减 + 续航**。

| 型号 | 规格 | 参考价 | 看点/疑点 |

| 国产教学款 10x 光变 USB PTZ（1688 白牌/海康 DS-UVC 系列） | 1080p，10x 光变，免驱 | ¥850~1600（[海康 800 万 4K 款 ¥858](https://s.1688.com/kq/-D3B2BCFEC5E0D1B5.html?beginPage=2)） | 参数漂亮价低；**必须实机验证：抗频闪（50/60Hz）设置、自动对焦策略、变焦后文字可读性** |

**摄像头硬门槛（所有候选到货必验）**：① 驱动/OS 设置里有 50/60Hz 抗频闪（拍投影防条纹）；② 自动对焦可用（对着投影画面不切来切去）；③ 3~8m 实测拍屏/白板，VLM 能读出 14pt 以上文字。

**摄像头为什么不走无线（2026-09-16 对齐结论）**：麦克风可以 2.4G 免驱（音频码流小、余量足），摄像头不行——2.4G 实际吞吐 10~20Mbps，1080p H.264 要 4~8Mbps 勉强塞下但余量为零；会议室 2.4G 频段被 WiFi/蓝牙（含我们的无线麦）挤占，视频最怕丢包；且大厂无 2.4G 免驱会议摄像头产品，白牌模块无保障。加之摄像头固定机位、无移动需求，无线收益≈0。线长 >5m 用有源 USB 延长线解决。若未来强制无线，只有 WiFi RTSP（≈C 方案开发量）或 5G 无线 HDMI 图传+采集卡（贵、链路复杂）两条路，均不建议。
