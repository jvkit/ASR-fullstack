# 会议纪要系统 2.0 — 硬件配置方案（对齐稿）

> 2026-09-16 ｜ 状态：调研与选型已完成，待对齐确认后进入采购

## 一、方案总述

会议纪要的视听采集方案定为：**会议级 USB 麦克风 + USB 摄像头，接入会场电脑，通过浏览器网页将音视频实时传输至服务器处理**。

选择这条路线的支撑：

- **音质与同步有保障**：USB 设备直连电脑，音频视频天然同步采集，不经网络摄像头二次压缩，识别所需的音质上限最高。
- **开发量最小、排期最稳**：浏览器即可采集推流，会场电脑无需安装任何软件，链路环节最少，风险点最少。
- **经济性合理**：同等预算下，USB 会议设备比网络设备便宜约三分之一到一半，且不需要额外的网络布线改造。

## 二、麦克风选型结论

| 配置项 | 结论 | 依据 |
|---|---|---|
| 形态 | 桌面会议全向麦 | 多人围桌场景标准方案，覆盖半径 3~6 米 |
| 采样率 / 位深 | 16 kHz / 16 bit | 语音识别模型的标准输入规格，规格对齐意味着零转换损失 |
| 接口 | USB，免驱标准 | 浏览器直接采集，会场电脑零安装 |
| 声道 | 单声道 | 区分说话人由声纹识别模型负责，多声道无实质增益 |
| DSP 能力 | 按会场情况配置回声消除 / 降噪 | 见"待对齐事项"第 1、3 条 |

补充说明：部分会场存在发言人声音经音箱扩音的情况，扩音会被麦克风二次收录、干扰识别，这类会场必须选用带**回声消除（AEC）**的会议级麦克风——这正是待对齐事项中需要确认的第一点。

## 三、摄像头选型结论

| 配置项 | 结论 | 依据 |
|---|---|---|
| 用途 | 覆盖手写白板，兼作 PPT 兜底 | 白板内容（手写、讲师遮挡、斜角度）由多模态大模型直接读图，不做 OCR |
| 分辨率 | 1080p 起步，远距离会场升级 4K | 投影文字可读性的下限 |
| 对焦 | 自动对焦 / 光学变焦必备 | 机位距屏幕通常 3~8 米，定焦无法满足 |
| 形态 | USB 云台（可遥控转向） | 白板需要讲师走动书写，固定机位容易拍空 |
| 其他必备 | 50/60Hz 抗频闪、宽动态 | 拍投影画面防条纹；会场"屏幕亮、环境暗"防过曝 |

另：会议中使用 PPT 时，推荐讲者在投屏电脑上直接通过网页共享屏幕，文字清晰度最高；摄像头仅负责白板等非电子内容。

## 四、部署条件

- 开会时场内提供**一台可插网线的电脑**，打开系统网页、授权麦克风与摄像头即可开始，无需专人值守操作。
- 设备到货后，我们先完成实测验收（远场拾音、扩音回声、白板识别、音视频同步），达标后定型交付。

## 五、待对齐确认事项

以下信息用于最终定型与采购，确认后 3 个工作日内出具具体型号与预算明细：

1. 开会时发言人声音是否会经音箱**扩音播放**（大教室、报告厅场景）？——决定是否必须配置回声消除
2. 会场最大人数与面积？——决定麦克风单机或双机级联
3. 会场环境噪声情况（空调、风扇、隔壁）？——决定降噪功能档位
4. 设备布线是否可接受？——有线方案稳定性最优，无线可作为替代
5. 本套硬件的预算区间？——当前建议：麦克风 1~3k，摄像头 1~2k
6. 采购流程与周期（统一采购 / 指定平台 / 报销）？——用于安排调研渠道与到货时间
