# 自研"内网会议纪要盒子"商业机会评估

> 目的：评估"麦克风阵列盒子 + 全内网部署软件"作为产品线的市场机会与利润空间，供决策参考。
> 调研日期：2026-09-04。结论先行，证据在后。

---

## 一、结论摘要

1. **市场真实存在且在快速增长**：AI 会议助手全球市场 2025 年约 35 亿美元（MRFR 预测 2035 年超 100 亿，CAGR 25%+）；国内企业级会议纪要工具 2025 年约 58.7 亿元，年增 23.5%（艾瑞口径）。**"数据不出内网"是其中增长最快的细分**——信创、金融、政务的私有化部署是政策驱动的刚需。
2. **竞品格局有明确空档**：讯飞硬件强但绑自家云/自家模型；WPS、云屋等有"私有化"但**要求客户接受他们的转写引擎**。**"软件部署进客户内网 + 用客户自己的模型 API"这个组合，主流厂商都不做**（他们靠模型订阅赚钱，不可能把模型主权交出去）。这是结构性空档，不是执行差距。
3. **硬件可以做轻**：不需要自研芯片。方案 = 成熟麦克风阵列模组（ESP32-Korvo / XMOS XVF3800 / RWK35xx 等，模组级百元级）+ WiFi/以太网模块 + 我们的服务。BOM 估 300-800 元，对小团队完全可承受。
4. **利润模型成立**：硬件薄利甚至成本价（对标讯飞全向麦 M2 售价 1599 元，我们同价位可给更好拾音硬件），**利润在部署服务费 + 软件年费**。这是"卖剃刀架"逻辑，刀片（软件服务）是持续性收入。
5. **主要风险**：硬件认证（SRRC/3C）与供应链的繁琐、销售依赖关系型渠道、以及讯飞若降价反击（但他们反击不了我们的核心差异化——模型主权）。

**一句话卖点：我们不卖录音笔，也不卖麦克风，我们卖"会议数据永远不出贵公司大门"的智能纪要系统。**

## 二、目标客户与需求真实性

### 2.1 谁在为"数据不出门"付真金白银

有法規硬约束的行业，不是"嘴上说说"：

| 行业 | 约束来源 | 典型场景 |
|---|---|---|
| 政务/党政军 | 等保三级、分保、信创目录 | 内部会议、党委会、涉密研讨 |
| 金融（银行/券商/保险） | 《数据安全法》《个人信息保护法》、金融监管总局《银行保险机构数据安全管理办法》（2024.12） | 投研会议、信贷评审、客户沟通记录 |
| 医疗 | 患者隐私、数据出境限制 | 病例讨论、会诊记录 |
| 律所/仲裁 | 客户秘密特权 | 案件合议、取证访谈 |
| 军工配套/科研院所 | 分级保护 | 项目会议 |

**证据**：2025 年"央国企、政务机构、学校、医院等泛政府类单位私有化部署 AI 大模型所需服务器开支空间约 1000 亿元"（财联社/行业测算）——大模型一体机已经证明这类客户**愿意花大钱买"数据不出门"**。会议纪要是其中高频刚需场景，但市面上缺少"轻量盒子 + 客户自选模型"的组合。

### 2.2 客户现在的替代方案与痛点

| 现有方案 | 痛点 |
|---|---|
| 讯飞录音笔（799-4000 元） | 录完导出再转写，数据上传讯飞云；涉密单位直接禁用 |
| 讯飞/WPS/腾讯会议"私有化版" | 软件是私有的，但**转写引擎也绑死在厂商**，模型不可替换、按年收费昂贵，且多为大型会议系统，复杂 |
| 人工纪要 | 慢、贵、漏 |
| 云端 AI 纪要（通义/元宝/飞书妙记） | 数据出内网，合规红线直接排除 |

**我们的位置**：恰好填"要私有化、但不想买整套视频会议系统、且想用自己的模型"这个空档。

## 三、竞品拆解

### 3.1 讯飞系（直接对标）

- **讯飞智能全向麦克风 M2**：1599 元，4 麦阵列、5 米拾音、蓝牙+USB（中关村在线经销商报价）。**必须搭配讯飞听见客户端**才能转写，转写走讯飞云（免费额度+会员付费）。硬件本身是好产品，但数据路径与"内网"诉求冲突。
- **讯飞会议宝/听见系列**：一体机思路，价格数万级，面向大型会议室。
- **他们的护城河**：ASR 算法积累、销售网络、品牌。
- **他们的弱点**：模型绑定（客户没法换成自己的模型）、内网部署不彻底、定制化服务弱（大厂不做小单定制）。

### 3.2 WPS 会议 / 云屋 / 小鱼易连（软件+方案商）

- WPS 会议有"纯私有化 + 离线语音引擎"方案（2026 年产品页明确写内网转写），小鱼易连服务了中组部等 60+ 部委。
- **共同点**：都是**重系统**（视频会议全家桶），单价高、实施重，对"只想解决纪要"的客户过重。
- **我们不打他们**：他们做"整个会议室"，我们做"会议纪要这一件事"。

### 3.3 总结：差异化定位图

```
        模型可替换（用客户自己的模型）
              ▲
              │  ★ 我们（唯一）
              │
  讯飞录音笔 ●│
  讯飞会议宝 ●│  ● WPS私有化
              │  ● 云屋/好视通
──────────────┼──────────────▶ 部署轻重
   轻量       │        重系统
```

## 四、产品方案（两条产品线，一条技术线）

### 4.1 两种规格，同一套软件

| | 小会议室版 | 大会议室版 |
|---|---|---|
| 场景 | 4-8 人，20㎡ 内 | 10-25 人，50-100㎡ |
| 收音 | 2-4 麦环形阵列，1 台盒子 | 多台盒子级联（以太网/WiFi 同步）+ 中心融合 |
| 拾音半径 | 5 米 | 每台 5 米 × N 台覆盖 |
| 硬件成本（BOM） | 约 300-500 元 | 约 800-2000 元（2-4 台 + 交换） |
| 建议定价 | 2999-4999 元 | 6999-14999 元 |

**级联可行性**：核心难点是"多路拾音融合成一条清晰音轨"。现有成熟路径：
- **波束成形**：XMOS XVF3800（4 麦阵列 + 内置 DSP：AEC/降噪/波束成形）已是商用级方案，开发板态约数百元
- **多设备同步**：同一内网做 NTP/PTP 时钟对齐后多路音频时间对齐，服务端做通道级融合（我们自己的服务器做，不算硬件难题）
- **人声分离**：cam++ 声纹聚类（已在我们的系统里跑通"说话人1/2"）在多通道下效果只会更好——通道间能量差提供额外说话人线索

### 4.2 "无法解决的难点"的诚实评估

| 难点 | 现状 | 对策 |
|---|---|---|
| 多人同时说话重叠 | ASR 行业难题，重叠段准确率显著下降 | 不承诺 100% 解决；做法：多通道提供 DOA（声源方位），重叠段按方位拆分 + 时间戳对齐；纪要里如实标注"（多人同时发言）" |
| 远场混响 | 3 米外信噪比骤降 | 阵列波束成形 + AEC（XVF3800 内置）；声学设计（吸音吊顶）交给集成商 |
| 回声（放音场景） | 外放时扬声器声音回灌 | AEC 算法成熟（模组自带），加分项 |
| 说话人"身份"归属 | 聚类只能给"说话人1/2"，不知道是谁 | 产品化解决：会前声纹注册（说一句话绑定姓名），这个功能我们系统已有雏形 |

### 4.3 硬件构成（盒子 BOM）

```
麦克风阵列（MEMS × 4）         ~50-100 元
前端 DSP（XVF3800 或同级）      ~150-300 元
主控 + 网络（ESP32-S3 或
  瑞芯微 + 百兆以太网）          ~80-200 元
外壳/PCBA/组装（小批量）        ~100-200 元
────────────────────────────────
BOM 合计                       ~400-800 元
（不含认证摊销、模具、包装）
```

> 认证与合规成本（一次性摊销）：SRRC 型号核准约 2-5 万/型号，3C 视产品类别，CCC 目录内约 1-3 万。**如果盒子走"以太网供电 + 不带无线"，可规避 SRRC**，成本大幅下降——工程上推荐首发有线版。

### 4.4 盈利模型（单客户示例：一家中型律所，3 间会议室）

| 项目 | 金额 | 说明 |
|---|---|---|
| 硬件（3 盒子） | 9,000-15,000 元 | 毛利 30-50% |
| 部署服务（一次性） | 5,000-10,000 元 | 装机 + 客户模型对接 + 培训 |
| 软件年费 | 3,000-8,000 元/年 | 纪要系统 license + 运维 |
| **首年合计** | **约 1.7-2.8 万元** | 后续每年纯软件收入 |

对比客户自建替代方案的年成本（讯飞企业版按席收费 / 人工纪要按次百元），客户算得过账。**50 家客户 = 年稳定软件收入 15-40 万 + 硬件销售 50-75 万**——对小团队是可观的第二曲线。

## 五、为什么我们能赢（和为什么可能输）

### 5.1 赢面

1. **模型主权是结构性差异**：大厂商业模式依赖模型绑定（转写是他们的印钞机），让客户用自己的模型 = 自断财路，所以他们**不会跟进**这个卖点。我们本来就不靠模型赚钱，靠部署和服务。
2. **客户自己的模型，效果反而可能更好**：客户内网大模型（如 Qwen 系）对行业术语的理解 + 我们的热词机制，垂直场景准确率可超过讯飞通用模型。
3. **轻**：一支笔都不到的实施量，安装即用；大厂方案做不到这个交付速度。
4. **价位带空档**：讯飞全向麦 1599（绑定云）vs 企业视频会议系统数万。我们 3000-15000 的"盒子+软件"落在无人区。
5. **销售的是服务不是硬件**：客户比价时拿我们和录音笔比硬件参数，我们必输；拿我们和"数据泄露风险 + 人工成本"比，我们必赢。**定价和话术的关键是锚定后者。**

### 5.2 风险与对冲

| 风险 | 程度 | 对冲 |
|---|---|---|
| 讯飞出"私有化全向麦" | 低-中 | 他们的私有化方案是整体会议系统，做一个"不带自家云的录音笔"等于革自己命，动作会慢；即便出了，我们仍握"模型可替换" |
| 硬件供应链/品控踩坑 | 中 | **轻做法起步**：先买现成 XVF3800 开发板/模组贴牌集成，验证需求后再考虑结案自主设计 |
| 认证周期拖累交付 | 中 | 首发有线版（免 SRRC），无线版二期 |
| 客户教育成本（"这不是录音笔"） | 高 | 演示即说服：现场 10 分钟从说话到出纪要，客户自己模型在跑 |
| 渠道依赖关系 | 中 | 先做身边资源：老师/学校的横向关系，一两个灯塔客户打磨案例 |

## 六、建议路线图

1. **第 1 步（现在，0 元）**：现有系统（已在跑）+ 一支 USB 全向会议麦克风（几百元，见选型文档）做成"样板间"，内网演示全流程——这是给老师/潜在客户看的活 Demo。
2. **第 2 步（1-2 个月，千元级）**：买 XMOS XVF3800 或 ESP32-Korvo 开发板，验证"盒子直推我们的 ws 接口"（协议就是现有 WebSocket，盒子端是固件开发量）。
3. **第 3 步（需求验证后）**：找 1-2 家灯塔客户（优先身边对数据敏感的单位）免费部署换案例和真实反馈。
4. **第 4 步（确认买单）**：再投入认证、外观模具、批量供应链。**在灯塔客户签单前，不发生大额硬件投入。**
