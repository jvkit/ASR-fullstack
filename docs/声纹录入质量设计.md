# 声纹录入质量设计（2026-09-15）

## 背景

旧录入只有"总时长 ≥3s"一个检查，"没准备好录 3 秒呼吸声"也注册成功；且声纹有两套
互不通气的存储（FunASR `speaker_db.json` 仅列表展示 / `speaker_enrolls/*.pcm` 认人
实际读取），DELETE 只删前者导致**假删除**（删了照样被认出）。

本次改造：**唯一权威库 = speaker_enrolls/*.pcm**，注册/列表/删除/检测全收敛到
diarize_svc；录入改为**智能注册**（宁缺勿滥：录入是全场识别的参照物来源，坏段一旦
入库会永久污染所有匹配）。

## 智能注册管线（POST /speaker_enroll）

raw PCM → RMS 归一化到 0.1（与会议管线 meeting_chunk 处理域对齐）→
fsmn VAD 切段（800ms 端点，注册要长段，识别要碎段，标准相反）→ 逐段过滤：

| 检查 | 阈值 | 说明 |
|---|---|---|
| 单段时长 | ≥ 2.0s | 短段是相似度拖尾主因（实测 <1.5s 段同人相似度可低至 0.29） |
| 段音量 | ≥ -42dBFS | 低于此为疑似环境音 |
| 爆音 | 顶格采样占比 ≤1% | 喷麦/敲桌/增益过高 |
| 一致性 | 排序 gap>0.12 截断 + 地板 0.45 | 见下方标定 |

→ 留 3~5 段（按时长优先，长段 embedding 更稳）写 `{name}_{ts}_{i}.pcm`，
旧段整批替换（同名重注册=换新一批段）。合格门槛：≥3 段且有效语音 ≥10s。

### 一致性双规则（关键设计）

相似嗓音**跨人**相似度可达 0.52~0.58（见标定），单一绝对阈值要么漏检要么误伤。
观察：同批真段与质心的相似度抖动仅 ±0.05，而他人段与主簇的落差 >0.2。因此：

1. 相似度降序后找**最大相邻落差**，>0.12 则低侧整组视为异质（他人插话/咳嗽/突发声）
2. 剩余段再做绝对地板（<0.45 逐段剔除）

迭代至收敛。实测（AISHELL GT 构造：45s 本人 + 7.9s 他人插入）：
他人两段 0.43/0.56 被正确剔除，本人五段 0.85+ 全留；注册后本人检测相似度 0.931。

## 参数依据（质心段数 / 段长 / 有效时长）

- **质心 3~5 段**：平均 N 个向量降噪 ~1/√N，1→3 段收益最大，5 段后饱和
  （多 utterance 平均是 SV 标准做法；admin 实测单段 0.484 → 三段质心 0.681）
- **段长 2~6s**：ERes2NetV2 针对短语音优化（[原论文](https://arxiv.org/html/2406.02167v1)），
  Res2Net 系在 2s 段提升最大、>4s 趋平（[Res2Net SV](https://arxiv.org/pdf/2007.02480v1.pdf)），
  训练分布就是 2~4s 短段
- **有效语音 ≥10s（目标 15~25s）**：注册随时长提升、30~60s 饱和
  （[x-vector 类实验](https://utoronto.scholaris.ca/bitstreams/b624c9ad-4605-4adc-b363-8fd814d509ff/download)）；
  我们是闭集认人 + 0.30 匹配阈值兜底，不需追饱和点

## 录入检测（POST /speaker_identify）

说 3~10 秒 → 命中库内谁 + 相似度 + 领先 margin + 全候选排行。
兼作**注册质量自查**：注册完立刻测，能稳定认出自己 = 注册合格（这是比任何
内聚度指标都直接的黄金标准）。判定线：`identify_match_threshold=0.40`。

VAD 切不出长段（安静/平稳语音）时回退整段 embedding。
