> v4 = 技术方案（"能用先"零自研，仍有效）；v5 = 把 v4 的两周理想排期换成
> **单人自下而上的现实估算**。原则：一个人 + 拒绝无效加班，墙钟时间与工作量分开管理。

## 〇、需求终稿（老师确认版）

```
会前：上传会议资料（多格式解析，挂会议档案）
会中：摄像头(拍PPT/白板) + 麦克风 → 服务器：声纹区分转写 + 定时快照送 VLM → 视觉状态
会后：导出纪要文档 = 会议内容 + 画面要点 + 会前资料融合（不做问答、不做向量库）
```

## 二、冲刺版排期（推荐，约 5 周，完整 demo 约 10/20）

同冲刺版，但 W1~W2 把 1.0 收尾做满 5 天（含匿名聚类），感知链路排进 W4。适合：老师对 1.0 还有验收要求的情况。

## 四、防加班三道闸

1. **本周与老师对齐排期**（用本文表格），"软件先行 demo"设为中途检查点——每两周可见产出，终期不被乱压

3. 硬件调研 3 天死线，拍板权在自己——唯一硬依赖绝不拖

## 五、技术方案（v4 全文有效，此处不重复）

- 感知层：VLM 通吃（OCR 已废弃），v1 定时抽帧直送 VLM 兼任变化检测，零自研
- 白板：状态机 + 增量更新（prompt 工程，非算法）
- 资料融合：L1 全量直塞 / L2 按文档切块，无向量库
- 数据安全决策点：云 VLM vs 本地 VLM（D1 实测前不承诺白板识别率）
- 硬件：摄像头 4K/关自动曝光/覆盖屏+白板（D1 三连测），麦克风全向麦 USB（见 02 调研）

## 六、给老师的一句话（含时序）

> 会前传资料、开会接摄像头麦克风（会场电脑开网页）、会后出纪要（内容+画面要点+资料对照）。方案全部用成熟技术拼装、本地部署。排期约 5 周，第 3 周可先演示软件链路（手机暂代摄像头），第 5 周完整版。
