# 002 · 认人：声纹向量、相似度阈值 0.30 是什么

> 目标：读完能回答"认人是靠什么工作的"、"0.30 是什么意思、为什么不是 0.5"、"margin 是干嘛的"。

## 1. 认人的本质：把声音变成指纹，比指纹

模型不认"声音"，只认数字。认人分两步：

**第 1 步：声纹模型（ERes2NetV2）把一段语音压缩成一个高维向量。**
长度 1~2 秒的语音 → 一个几百维的向量。可以把它理解成**指纹**：同一个人说的不同话，向量很接近；不同人，向量离得远。这就是"声纹 embedding"。

**第 2 步：比对新向量 vs 注册库。**
开会前每个人录几段声纹，服务器把每段也算成向量存起来。认人时算一个叫**余弦相似度**（cosine similarity）的数：

- 值域 [-1, 1]，越接近 1 越像
- 同一个人：通常 0.4 ~ 0.7
- 陌生人：通常 0.3 以下

整个认人就是一句代码：`相似度 = dot(这句话的向量, 库里某人的向量)`，然后谁的分数最高选谁。

## 2. 阈值 0.30：及格线

有了分数，需要一个**及格线**才敢贴名字：

```
相似度 0.52 → 是 admin（≥0.30，敢贴）
相似度 0.18 → 不敢贴，标"说话人N"（<0.30，宁可匿名不瞎猜）
```

这个 0.30 就是配置里的 `reannotate_name_threshold`，批次、会末终版、手动重标注三处共用这一个值。

### 0.30 是怎么定的（不是拍的）

实测出来的分数分布：

| 情况 | 相似度 |
|---|---|
| 注册人真实匹配 | 0.44 ~ 0.61 |
| 陌生人/未注册的段 | 大多 < 0.30 |

0.30 就是安全区的**下限**：注册人最低也有 0.44，陌生人最高很少碰 0.30，中间留了一段缓冲带。

### 及格线定太高会怎样

历史上真出过事：曾经用 0.5 当阈值，结果一句话实时转写明明认出是 admin（得分 0.502），会末重标注却因为换了阈值被判匿名——**同一个系统前后矛盾**。而且阈值越高 → 越多人"挂科"变匿名 → 匿名句子只能继承邻居名字 → 未注册人坍缩成邻居的风险放大。

一句话：**阈值是"宁可少说，不可说错"的程度旋钮**。0.30 是我们实测下来"说对"和"少说"的平衡点。

## 3. margin：必须比第二名高出一截

光总分过线还不够。想象一种情况：

```
这句话对 admin  0.31  ← 过线了
这句话对 蒋泽鹏 0.29  ← 也差得不远
```

模型其实"没把握"，两个都有点像（可能是第三人，也可能是音频质量差）。如果只看 top1 过线就贴名字，这种模糊情况会频繁贴错。所以加了一个条件：

```
top1 - top2 ≥ 0.04（change_margin）才贴名字
```

**必须领先第二名至少 0.04，才算"有把握"。** 不够领先 → 视为没认出来，走匿名。

## 4. 认人决策的完整规则（生产代码实际逻辑）

对每一句语音，按顺序：

1. **整句预检**：整句算一个向量，相似度 ≥0.30 且领先第二名 ≥0.10（merge_margin，比常规更严格）→ 直接判"单人句"，不用拆
   - 为什么更严格：要免拆，就得非常确定整句是同一个人
2. **不满足 → 滑窗拆句**：0.6 秒窗口、0.3 秒步进，每小窗各认一次（每窗要求 ≥0.30 且 ≥0.04 领先）
3. 滑窗结果后处理：抖动修正（孤立的"不同"不可信）→ 碎段并入邻居 → 换人边界取重叠区中点
4. **全部没认出来 → 匿名，继承相邻句的名字**

第 4 条是双刃剑，务必理解：**匿名继承假设"邻居是谁你就是谁"**——全员已注册时这是合理先验；有未注册的人时，他会整条被染成邻居的名字（幼儿园会全场坍缩成 admin、DER 53% 的事故就是这个机制）。所以现在的产品对策是：**开会前把参会人声纹都录上**。

## 5. 想调阈值时怎么验证

不要凭感觉，用调试脚本打分：

```bash
# 拿一段音频的某个时间段，打印它对声纹库每个人的相似度
ssh gpu "cd ~/jvkit/asr && venv/bin/python ai-script/score_seg.py <wav> --seg <开始秒>,<结束秒>"
```

输出会告诉你：这句话对每个人各多少分、领先多少。看分布再决定阈值往哪动。

## 6. 一句话总结

- 认人 = 声纹指纹 + 余弦相似度，本质就是一次打分
- 0.30 = 及格线（实测注册人 0.44~0.61，陌生人 <0.30）
- margin = 必须比第二名高 0.04，防"两个都有点像"的硬贴
- 阈值宁低勿高：高了anonymous多，匿名继承会放大坍缩
