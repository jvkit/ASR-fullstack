# 001 · 声音的预处理：响度归一化 与 VAD 切句

> 目标：读完能回答"归一化是忽略小声还是放大小声"、"VAD 的 250ms 是什么、调大调小各有什么后果"。

## 1. 先建立直觉：模型"听"声音的方式和人不同

人对声音的判断是自适应的——自动放大远处的人声、忽略空调嗡嗡声。模型没有这种本事，它只认**数值**。音频进模型前是一串数字（振幅），振幅越大=声音越响。

模型训练时听的都是"音量正常"的语音。如果你给它一段会议室远场录音——整体音量只有正常水平的十分之一——它会觉得"大半段都是安静的"，于是：

- 小声说话的人 → 被判成"静音"，**整句丢失**（这就是评测里 miss 错误的来源）
- 连带的，切句、认人、转写全部无从谈起

## 2. 响度归一化：不是"忽略小声"，恰恰相反

我们做的 RMS 归一化，逻辑一句话：**把整段音频的响度按比例拉到模型熟悉的水平（RMS≈0.1）**。

```
类比：老师傅听不清录音笔里的会议，你把音箱音量旋钮拧大——
     所有人的声音都等比例变响，没有谁被忽略，只是整体更清楚了。
```

RMS 就是"这段音频的平均响度"。实测它 0.01（太轻）→ 整体放大 10 倍 → 0.1。它**不区分语音和噪音**，一视同仁地放大。

### 它能救什么、救不了什么

| 情况 | 归一化能救吗 |
|---|---|
| 整场会议大家都说得很轻（设备远、增益低） | ✅ 能，整体放大后 VAD 就都"听见"了（实测验证过，大房间漏检因此改善） |
| 某个人坐得远说得特别轻，别人正常 | ❌ 救不了。整体放大后他还是相对最轻的那个，信噪比不够，VAD 照样漏 |
| 房间回音大、收音丢帧、底噪高 | ❌ 完全无效。糊的输入放大后还是糊的 |

**所以归一化的定位：把"音量"这个变量从问题里消掉，让模型只面对"信噪比"这一个问题。剩下的问题归硬件管。**

## 3. VAD：先回答"哪里有人说话"，才有后面的一切

VAD（Voice Activity Detection，语音活动检测）是流水线的第一道工序，输出语音段的边界：

```
一段 30 秒的音频 → VAD → [[0.0s, 3.2s], [4.1s, 9.8s], [10.0s, 12.5s], ...]
                      "这几段有人说话，中间是静音/噪音"
```

**为什么必须先切句**：转写模型和认人模型都以"句"为单位工作。整段 30 秒直接问认人模型"这是谁"，它只能回答"整段最像谁"——句内一换人就完蛋。切成句，才能逐句问"这句是谁"。

## 4. max_end_silence_ms：切句的"耐心值"

关键参数只有一个：`max_end_silence_ms`——**一句话中间的停顿持续多久，就判定"这句话说完了"**。

```
停顿 0.15s（换气）    ← 小于 250ms，不切，还是同一句
停顿 0.30s（想了想）  ← 超过 250ms，切！前句结束，后句开始
```

### 这个参数的来历（我们踩过的路）

| 阶段 | 值 | 说明 |
|---|---|---|
| FunASR 模型出厂默认 | 800ms | 切出的句子特别长，句内换人频繁 |
| 实时版（已废弃） | 350ms | 当时的调优 |
| **现在非实时版** | **250ms** | 当前生产值 |

### 调小（如 100~150ms）会怎样

收益：
- 切点更贴近真实停顿，句子边界更准
- 长句变少 → 句内换人变少 → 滑窗拆句的压力变小

代价：
- 句子变碎 → 每句时长变短 → **认人可用的声音素材变少**
- 我们的认人逻辑里，<0.5s 的段几乎认不出（代码里 <0.25s 的窗直接跳过），碎句只能"继承邻居的名字"
- 碎句越多、匿名继承越频繁，未注册人坍缩的风险越大
- ASR 调用次数变多，变慢变贵

**"之前切太碎导致区分失败"——你记得没错，但那正是实时版的问题。现在非实时版攒批 8~15 秒，碎不碎不取决于节奏而取决于这个参数本身。**

### 调大（如 400~600ms）会怎样

收益（假设，待验证）：
- 说话收尾时声音是渐弱的，VAD 往往在尾巴还听得见时就提前关段——尾巴被丢掉，评测里计为 miss。耐心值大 = 多等一会儿再关，**有望保住弱音尾巴，降低漏检**
- 短停顿（换气、顿一下）不再切断，句更完整，认人素材更足

代价（假设，待验证）：
- 相邻两句话如果停顿短，会被**合并成一句**——两人各说半句被缝在一起，句内换人 → 混淆错误（conf）上升

### 当前主要矛盾决定扫参方向

看我们的实测成绩：S会 5.7% / M会 17.2% / L会 14.2%，其中 **M会 43 秒 miss（漏检）是大头，混淆只有 5 秒**。

- 想解决漏检 → 该试**调大**（400/600），赌它保住弱音尾巴
- 调小对漏检**没有直接帮助**（漏掉的是"根本没被检出的语音"，不是"切点不准"），反而引入碎句风险

**这就是为什么实验设计是 250 → 400 → 600 往上扫，而不是往下。** 但注意上面标了两次"假设"——FSMN VAD 内部对尾音的具体处理是黑盒，扫参实测是唯一可靠的裁决方式。做实验的意义就是：不拍脑袋，让 DER 数据说话。

## 5. 一句话总结

- 归一化 = 把音量旋钮拧到模型舒服的位置，谁也不忽略，但救不了"某个人就是轻"
- VAD = 先标出"哪里有人说话"，`max_end_silence_ms` 是它的耐心值
- 耐心值调小 → 句子碎 → 认人素材不足；调大 → 句子长 → 可能缝住两个说话人
- 我们的当前错误大头是漏检，所以实验往**大**扫（250/400/600）
