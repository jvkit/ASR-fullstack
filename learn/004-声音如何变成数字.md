# 004 · 声音如何变成数字，数字如何变成特征

> 目标：读完能回答"声音在电脑里到底长什么样"、"平面波是什么"、"声纹向量是从哪一步变出来的"。
> 这一篇是前面所有概念（RMS、VAD、embedding、相似度）的地基。

## 1. 声音是什么波：不是平面波，是"一推一拉"的波

物理课上"平面波"是理想化的概念（波前是平面的波）。真实的声音简单得多：

**声音 = 空气压力随时间的高低起伏。** 人说话时声带振动，把周围的空气一会儿压缩、一会儿拉伸，这个疏密交替就像水面涟漪一样扩散出去，推到麦克风膜片上，膜片跟着振动，变成电压信号。

对工程来说只要记住一个画面：**声音是一条随时间起伏的曲线**。横轴是时间，纵轴是"压力偏离正常值多少"。没有立体结构，没有平面——**一维曲线，就这么多**。

```
压力
 ↑      ∩∩   ∩
 |     /  \ / \      ← 声带振动造成的一连串起伏
 |____/____\__/________→ 时间
```

- 曲线**上下摆得多快** → 音高（频率）。成年男性基频约 100Hz（每秒振动 100 次），女性约 200Hz，这就是"男女声不一样"的物理来源
- 曲线**摆得多大** → 响度。摆动幅度大 = 声音响

## 2. 第一次变身：波 → 一串数字（采样）

电脑存不下连续曲线，只能存数字。于是做一件事：**每秒把曲线的瞬时高度量 16000 次**，每个高度记成一个整数。

- **采样率 16kHz** = 每秒切 16000 个点（我们系统全部用这个）
- **16bit** = 每个点用一个 -32768 ~ +32767 的整数表示（0 表示安静，绝对值越大越响）

这就是我们系统里 `.pcm` 文件的全部内容：**纯数字，一秒 16000 个，别无其它。**

```
时间上连续的曲线:  ⌒⌒⌒⌒⌒⌒
采样后:            ↑  ↑  ↑  ↑  ↑  ↑
                  120 -35 800 2400 900 50   ← 6 个点，6 个整数
```

算个数感受一下尺度：一次"6 秒滑窗" = **96000 个整数**。"零幺六零幺七"五个字 ≈ 2 秒 ≈ 32000 个数字。

## 3. 第二次变身：数字 → 图（特征提取）

把 96000 个原始数字直接喂给神经网络有两个问题：太多、太"raw"——模型从原始波形里直接学东西太难了。所以要先做一层加工，把数字变成**更有信息量的表示**，这层加工叫"特征提取"。最重要的一个：

### 频谱图（spectrogram）：把"波形"翻译成"乐谱"

思路：任一小段声音（比如 25 毫秒 = 400 个点）里同时混着很多频率的成分——男声低频粗、齿音高频碎。对每一小段做一次数学变换（傅里叶），回答一个问题：

**"在这 25ms 里，低频有多强、中频有多强、高频有多强？"**

一小段得到一个"频率强度分布"，把整段音频的所有小段竖着拼起来，就得到一张**时间 × 频率**的灰度图——**频谱图**。它长得就像钢琴卷帘：

```
频率(高) │      ░░              ░░
         │  ▓▓  ░░  ▓▓      ▓▓  ░░
         │  ▓▓▓▓░░  ▓▓▓▓  ▓▓▓▓▓▓
频率(低) │▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓
         └──────────────────────→ 时间
```

看人说话在这张图上是什么样：**每个字是一个横着的"斑块"**—— consonant（声母）高频碎、vowel（韵母）低频实。你肉眼都能看出字和字之间的边界——VAD 和 ASR 模型看这张图，比看原始波形容易得多。

### 从频谱图再往下走几步

- **F0（基频曲线）**：只把"声带振动多快"这一条线抽出来，就是音高曲线——男女声的差异在这根线上最明显
- **MFCC**：模拟人耳听觉的压缩表示（人耳对频率的感知不是线性的），老一代系统的标准输入
- **embedding（声纹向量）**：上面那些还是"给人看的特征"，最后一步是**用神经网络把整个片段的频谱图压成一个 192 维的向量**——这就是反复说的"声纹指纹"。它不再是"特征"，而是"结论"：192 个数，编码了"这段声音是谁"

## 4. 我们系统里这些数字各在哪一步

把前面学过的所有概念钉在这条流水线上：

```
空气振动
  │  麦克风
  ▼
电压波形 ──────────────── 物理世界到此为止
  │  采样 16kHz / 16bit
  ▼
.pcm 文件（每秒 16000 个整数）── learn 里说过的"6秒窗=96000个数"就在这
  │  RMS 归一化（把整数整体缩放，响度拉到 0.1 附近）
  │  能量计算（振幅²的平均 → VAD 靠这个找"哪里有人说话"）
  ▼
VAD 切出句子边界
  │  每句 → 频谱图 → ERes2NetV2 网络
  ▼
192 维声纹向量 ─────────── learn/002 的"打分""0.30 及格线"在这
  │  与注册库质心算余弦相似度（两个 192 维向量的夹角）
  ▼
"这句话 82% 像蒋泽鹏"
```

## 5. 回看之前所有"黑话"，现在都是具体的东西

| 之前的词 | 现在的理解 |
|---|---|
| RMS 0.1 | 那 16000 个整数/秒的均方根，整体响度的度量 |
| 16k/16bit | 每秒 16000 个点、每个点 -32768~32767 |
| 6 秒滑窗 | 96000 个整数的一小段 |
| VAD | 看能量曲线 + 模型，找"哪里是语音哪里是静音" |
| embedding | 一段语音经网络压缩后的 192 个数 |
| 相似度 0.525 | 两个 192 维向量的夹角余弦 |
| 频谱图 | 时间×频率的图，字是一个个斑块 |

## 6. 一句话总结

声音在电脑里就是**一条曲线 → 一串整数 → 一张时间×频率的图 → 一个 192 维向量**。前面学的所有概念——响度、VAD、声纹、相似度——都是这条流水线上某一站的具体操作。**数字从来不神秘，神秘的是每一步"为什么这么变"，而每一步的理由都已经讲过了。**
